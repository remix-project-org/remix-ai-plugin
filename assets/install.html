Remix Solidity

Add Remix Solidity to Claude

The plugin is not published to a public marketplace, so you add it by hand. Choose a way to add it and open it to see the steps.

Claude Code pluginManual install Skills and MCP tools in one install, added from the Remix Labs marketplace.

  1. Add the marketplace

    claude plugin marketplace add remix-project-org/remix-ai-plugin

    Inside a Claude Code session, use /plugin marketplace add remix-project-org/remix-ai-plugin instead. Claude Code reads the repository with the git credentials already on your machine.

  2. Install the plugin

    claude plugin install remix-solidity@remixlabs

  3. Check that it is installed

    claude plugin list

  4. Use the skills

    The plugin adds two skills, namespaced with the plugin name:

    /remix-solidity:deploy-contract
    /remix-solidity:call-contract

Update

claude plugin marketplace update remixlabs
claude plugin update remix-solidity@remixlabs

Auto-update is off by default for marketplaces that are not Anthropic's own.

Remove

claude plugin uninstall remix-solidity@remixlabs
claude plugin marketplace remove remixlabs

Removing the marketplace also uninstalls every plugin you installed from it.

The plugin connects to the Remix Solidity server at {{BASE_URL}}/mcp. It can prepare transactions that you review and sign in your own browser wallet, and the server never holds your keys. Claude Code's documentation advises: "Make sure you trust a plugin before installing, updating, or using it."

MCP connectorManual install Add only the server, without the plugin's skills.

Choose either the plugin or this connector: both give Claude the same server.

Claude Code

claude mcp add --transport http remix-solidity {{BASE_URL}}/mcp

By default the server is stored for the current project only. Add --scope user to use it in all your projects.

Claude on the web

  1. Open the custom connector form

    On Pro and Max, go to Customize, then Connectors, then + Add, then Add custom connector. On Team and Enterprise, an Owner goes to Organization settings, then Connectors, then Add, then Custom, then Web. Button labels vary by plan.

  2. Enter a name and this URL

    {{BASE_URL}}/mcp

  3. Choose No sign in

    The server needs no account or token.
